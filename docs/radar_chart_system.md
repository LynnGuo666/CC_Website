# 玩家能力雷达图系统

## 概述

雷达图系统是一个六维能力评估工具，用于可视化玩家在不同游戏中的综合表现。系统基于玩家的**排名**和**标准分**计算六个核心维度的能力值。

## 六大维度

| 维度 | 说明 | 代表游戏 |
|------|------|----------|
| **武力 (Combat)** | 战斗能力、击杀效率 | 斗战方框、空岛战争 |
| **协作 (Cooperation)** | 团队配合、协同作战 | 斗战方框、跑酷追击 |
| **策略 (Strategy)** | 战术思维、决策能力 | TNT Run、跑酷追击 |
| **爆发 (Burst)** | 瞬间爆发、关键时刻表现 | 空岛战争、雪球乱斗、TGTTOS |
| **知识 (Knowledge)** | 游戏理解、机制掌握 | Bingo |
| **身法 (Movement)** | 移动技巧、操作精度 | TNT Run、跑酷战士 |

## 计算公式

### 单局游戏表现 ($P_g$)

$$P_g = 0.5 \times S_{rank} + 0.5 \times S_{std}$$

#### A. 排名分 ($S_{rank}$)
基于玩家在该局的排名：

$$S_{rank} = 100 \times \left(1 - \frac{\text{排名} - 1}{\text{房间人数} - 1}\right)$$

- 第一名 = 100 分
- 最后一名 = 0 分

#### B. 标准分表现 ($S_{std}$)
基于玩家标准分相对于预期平均分的表现：

$$S_{std} = \left( \frac{\text{玩家标准分}}{\text{预期平均标准分}} \right) \times 50$$

其中，预期平均标准分 = 15000 / 赛事总人数（通常为 50）= 300

**示例：**
- 标准分 = 300（平均水平） → 50 分
- 标准分 = 600（2 倍平均） → 100 分
- 标准分 = 750（2.5 倍平均） → 125 分 ✨

> **注意**：标准分表现**无上限**，优秀玩家可以突破 100 分！

### 维度能力值聚合

每个维度的最终分数通过加权平均计算：

$$Score_D = \frac{\sum (\text{单局表现} \times \text{游戏权重})}{\sum (100 \times \text{游戏权重})} \times 100$$

**游戏权重：**
- 核心维度（High Impact）：1.0
- 辅助维度（Medium Impact）：0.6

## API 接口

### 获取玩家综合雷达图

```http
GET /api/users/{user_id}/radar
```

**响应示例：**
```json
{
  "武力": 47.0,
  "协作": 55.0,
  "策略": 66.8,
  "爆发": 68.5,
  "知识": 50.6,
  "身法": 68.4
}
```

### 获取玩家在特定赛事的雷达图

```http
GET /api/users/{user_id}/radar?match_id={match_id}
```

**参数：**
- `match_id` (可选): 赛事 ID，如果指定则只计算该赛事的数据

## 分数解读

| 分数范围 | 等级 | 说明 |
|---------|------|------|
| 0-30 | D | 入门水平 |
| 30-50 | C | 一般水平 |
| 50-70 | B | 良好水平 |
| 70-90 | A | 优秀水平 |
| 90-100 | S | 顶尖水平 |
| **100+** | **S+** | **超凡表现** ✨ |

## 设计理念

1. **平衡性**：排名和标准分各占 50%，既认可胜负，也认可个人实力
2. **公平性**：使用标准分而非原始分数，消除不同游戏间的分数差异
3. **激励性**：允许分数突破 100，鼓励玩家追求极致表现
4. **区分度**：即使输掉比赛，"Carry 全场"的玩家也能获得高分

## 示例场景

### 场景 1: God Gamer
- **表现**：所有游戏第 1 名，标准分均为平均分的 2.5 倍
- **结果**：六维全满，每个维度 **112.5** 分

### 场景 2: Carry 但输了
- **表现**：排名第 10（中游），但标准分是平均分的 3 倍（杀疯了）
- **结果**：相关维度可达 **115.8** 分，认可个人实力

### 场景 3: 混子
- **表现**：排名第 25（中游），标准分平平（1 倍平均）
- **结果**：各维度约 **50** 分（及格线）
